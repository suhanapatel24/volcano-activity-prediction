# Supplied GVP workbook profile

File: `GVP_Eruption_List_Holocene_20260424.xlsx`

Sheets: `Info`, `Eruption List`.

The Eruption List contains 9,918 data rows and 22 columns after its title row. Key fields include Volcano Number, Volcano Name, Eruption Number, Eruption Category, Area of Activity, VEI, VEI Modifier, start/end date fields, uncertainty fields, and Evidence Method (dating).

Observed profile:
- confirmed eruptions: 9,918
- unique volcano numbers: 854
- known numeric VEI: 7,725
- missing VEI: 2,193 (22.11%)
- numeric VEI values range from 0 through 7 in this export
- Start Year spans -55,500 through 2026

The very early historical dates and uncertainty/modifier fields are reasons to treat this as an exploratory historical catalog rather than a clean modern forecasting dataset.
